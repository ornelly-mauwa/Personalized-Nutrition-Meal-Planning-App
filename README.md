# myMeal

A full-stack mobile application that connects users with certified nutritionists to create personalized diet plans based on allergies, preferences, and health goals.

## Overview

This platform allows users to receive tailored meal plans while enabling nutritionists to manage multiple clients. The system includes role-based access for Users, Nutritionists, and Admins.

## Features

- 🔐 Role-based authentication (User / Nutritionist / Admin)
- 🥗 Personalized diet plans
- 🚫 Allergy and preference tracking
- 💧 Water intake monitoring
- 📈 Daily meal tracking
- 👩‍⚕️ Nutritionist-client management
- 🛠 Admin role management

## Tech Stack
